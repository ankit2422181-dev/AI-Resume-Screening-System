# AI Resume Screening & Candidate Ranking System

An AI-powered recruitment automation platform that evaluates resumes against job descriptions using NLP, semantic search, vector embeddings, and machine learning techniques.

## Features

- Resume Parsing
- Candidate Ranking
- ATS Style Matching
- Semantic Search
- Recruitment Automation
- Intelligent Resume Analysis
- NLP-Based Candidate Evaluation

## Technology Stack

- Python
- Streamlit
- NLP
- Sentence Transformers
- Scikit-Learn
- OpenAI
- LangChain
- ChromaDB

## Workflow

Job Description
↓
Resume Upload
↓
Text Extraction
↓
Embedding Generation
↓
Similarity Matching
↓
Candidate Ranking
↓
Recruitment Insights
